# Rock Paper Scissors Game 🎮

A simple and interactive **Rock Paper Scissors** game built with **HTML, CSS, and JavaScript**. Play against the computer and see if you can win!

![Gameplay](Images/gamescreenshot.png)

## ⚙️ Features
- Interactive UI with choices for rock, paper and scissors
- Score tracker for player and computer
- Visual effects on winning or losing

## 🛠 Technologies Used
- HTML
- CSS
- JavaScript
